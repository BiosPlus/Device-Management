## Pre-Sonoma (macOS 13 and older)

Pre-Sonoma macOS lacked a reliable MDM-driven update workflow. Apple's design is user-initiated first — MDMs could define an update schedule, but the actual kickoff still required user action.

The recommended approach is [Nudge](https://github.com/macadmins/nudge).

- Deploy the Nudge Suite package from the [macadmins GitHub releases page](https://github.com/macadmins/nudge/releases).
  - Scope deployment to a device group in your MDM with a condition matching OS version older than 14.0.
- Configure a Nudge policy using one of the two options below (current as of 2024-01-31):

### Option One: The all-in-one (AIO) Nudge mobileconfig file

Deploy a mobileconfig file to Macs with a full configuration built in. The mobileconfig is available in the resources directory of this repository.

### Option Two: The web-based Nudge configuration

Deploy a mobileconfig file to Macs that points to a remote configuration source (e.g. a raw file hosted on GitHub). The mobileconfig and JSON configuration files are available in the resources directory of this repository.
